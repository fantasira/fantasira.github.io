01

GameApp — Gestion de jeux de société

Application web full-stack développée avec Angular et Symfony dans le cadre de ma Licence 3 MIAGE. Réalisée en équipe, elle permet de gérer un catalogue de jeux de société et les parties organisées par les utilisateurs. L'application propose également un système d'authentification, une gestion des rôles, un générateur de soirée et un quiz interactif consacré aux jeux enregistrés.

Angular TypeScript Angular Material Symfony PHP API Platform API REST Doctrine ORM SQLite HTML CSS Docker Git Bitbucket Visual Studio Code Projet en groupe

Date : du 4 mai 2026 au 7 mai 2026

Contexte : projet universitaire réalisé en équipe dans le cadre du deuxième contrôle continu du module Framework Web 2 de la Licence 3 MIAGE.

Fonctionnalités principales : consultation et gestion d'un catalogue de jeux de société, ajout, modification et suppression des jeux, gestion des parties organisées par les utilisateurs, association d'un jeu à une partie, inscription, connexion et déconnexion, gestion des rôles utilisateur et administrateur ainsi que restriction des fonctionnalités selon le profil connecté.

Gestion des jeux et des parties : les administrateurs peuvent ajouter, modifier et supprimer les jeux présents dans le catalogue. Les utilisateurs peuvent consulter les jeux, créer des parties et gérer uniquement les parties qui leur sont associées. Chaque partie contient notamment un lieu, un nom, une date, un nombre de joueurs, une durée, un commentaire et un jeu sélectionné.

Extensions réalisées : développement d'un générateur de soirée permettant de filtrer les jeux selon le nombre de joueurs et le temps disponible, puis de sélectionner aléatoirement un jeu compatible. L'application intègre également un quiz dynamique générant des questions à partir des informations présentes dans la base de données : mécanique, auteur, année de publication et éditeur.

Mes contributions : participation à la mise en place de l'inscription et de la connexion des utilisateurs, création de la logique d'authentification, hachage sécurisé des mots de passe, attribution des rôles utilisateur et administrateur et participation à la gestion des autorisations. J'ai également travaillé sur les extensions du projet, notamment le générateur de soirée et le quiz interactif.

Architecture : frontend développé avec Angular et TypeScript utilisant des composants standalone, des formulaires et des services HttpClient. Le backend repose sur Symfony, API Platform et Doctrine ORM. Les entités sont exposées sous la forme de ressources d'une API REST consommée par l'application Angular. Les données sont enregistrées dans une base SQLite et l'environnement de développement est conteneurisé avec Docker.

Bilan : ce projet m'a permis de renforcer mes compétences en développement full-stack avec Angular et Symfony, en création et consommation d'une API REST, en utilisation d'API Platform, en gestion des relations entre entités avec Doctrine, en authentification et en contrôle des accès. Il m'a également permis de développer des fonctionnalités basées sur le filtrage, la génération aléatoire et la manipulation dynamique de données.

WeLab Cosmétique

Elle propose un espace utilisateur et un espace administrateur communiquant avec une API REST développée avec Symfony.

Angular TypeScript Symfony PHP CSS HTML Doctrine API REST SQLite Docker Docker Desktop GitBucket WinDesign Visual Studio Code Projet en groupe

Date : 20 novembre 2025 au 4 mai 2026

Projet : réalisé en groupe dans le cadre de ma Licence 3 MIAGE.

Fonctionnalités principales : authentification et inscription des utilisateurs, gestion des profils, création et suivi de projets, réservation de laboratoires par date et créneau horaire, suivi du statut des demandes, gestion des documents, notifications, matériels, stages et prestations.

Espace administrateur : gestion des utilisateurs, projets, réservations, laboratoires, matériels, prestations, stages, documents et notifications. L'administrateur dispose également d'un tableau de bord lui permettant de suivre et de traiter les différentes demandes.

Bilan : ce projet m'a permis de consolider mes compétences en développement full-stack, Angular, Symfony, conception d'API REST, gestion de bases de données avec Doctrine et communication entre frontend et backend. Medico2 — Gestion de consultations médicales

Application web développée avec Symfony dans le cadre de ma Licence 3 MIAGE. Réalisée en équipe, elle permet de gérer les utilisateurs, les consultations, les traitements et les rendez-vous médicaux à travers des interfaces adaptées aux administrateurs, aux médecins et aux patients.

PHP Symfony Doctrine ORM Twig SQLite Bootstrap HTML CSS Docker Git Bitbucket Visual Studio Code Projet en groupe

Date : du 17 février 2026 au 2 mars 2026

Contexte : projet universitaire réalisé en équipe dans le cadre du module Framework Web 2 de la Licence 3 MIAGE.

Fonctionnalités principales : authentification des utilisateurs, gestion des rôles et des autorisations, création et administration des comptes, gestion complète des consultations médicales, association d'un patient et d'un médecin à une consultation, gestion des traitements, gestion des rendez-vous, recherche, tri et pagination des données.

Gestion des profils : l'application propose des fonctionnalités différentes selon le rôle de l'utilisateur. L'administrateur peut gérer les utilisateurs, les consultations et les rendez-vous. Le médecin peut consulter les informations médicales qui lui sont associées, tandis que le patient dispose d'un accès à ses propres consultations et rendez-vous.

Mes contributions : développement du formulaire de création d'une consultation, mise en place de la modification et de la suppression des consultations, participation à la gestion des autorisations selon les rôles administrateur, médecin et patient, amélioration de l'interface avec Twig et Bootstrap, participation à la création du modèle de mise en page commun et du système de thèmes graphiques.

Architecture : application construite selon l'architecture MVC de Symfony. Les entités et leurs relations sont gérées avec Doctrine ORM, les formulaires avec le composant Form de Symfony, les traitements avec des contrôleurs et l'affichage avec des templates Twig. La base de données utilisée est SQLite.

Bilan : ce projet m'a permis d'approfondir l'utilisation de Symfony, de Doctrine ORM et de Twig. J'ai renforcé mes compétences en création de formulaires, en développement d'opérations CRUD, en gestion des relations entre entités, en contrôle des accès et en développement collaboratif avec Git et Bitbucket.

Medico — Gestion de consultations médicales

Application web réalisée au début de ma Licence 3 MIAGE avec le framework Django. Développée en équipe de quatre étudiants, elle permet à un médecin de gérer les consultations de ses patients ainsi que les traitements et les analyses médicales associés.

Python Django SQLite Bootstrap HTML Docker Git Bitbucket Visual Studio Code Projet en groupe

Date : du 3 novembre 2025 au 7 novembre 2025

Contexte : projet universitaire réalisé en équipe de quatre étudiants dans le cadre du module Framework Web 1 de la Licence 3 MIAGE.

Fonctionnalités principales : affichage de la liste et du détail des consultations, ajout, modification et suppression d'une consultation, gestion des traitements associés à chaque consultation et gestion d'analyses médicales.

Extension réalisée : ajout d'un module permettant d'associer une ou plusieurs analyses médicales à une consultation, avec le nom de l'analyse, le lieu, la date de retour et une description.

Mes contributions : participation au développement de plusieurs fonctionnalités Django à travers les modèles, vues, formulaires, routes et templates. J'ai notamment travaillé sur l'affichage du détail d'une consultation, la liste des consultations, la création du modèle Traitement et sa relation avec les consultations. J'ai également participé à la conception et à la documentation de l'extension consacrée aux analyses médicales ainsi qu'à différentes modifications réalisées collectivement.

Architecture : utilisation de l'ORM Django pour gérer les modèles et les relations, de ModelForm pour les formulaires, des vues et templates Django pour l'affichage, de SQLite pour la persistance des données et de Bootstrap pour la mise en forme de l'interface.

Bilan : ce projet m'a permis de découvrir les fondamentaux du framework Django, les migrations, les relations entre modèles, les formulaires, le routage et l'héritage de templates. Il m'a également permis de travailler rapidement en équipe avec Git et Bitbucket.
