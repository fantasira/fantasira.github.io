WeLab Cosmétique

Application web full-stack réalisée dans le cadre de ma Licence 3 MIAGE. WeLab Cosmétique est une plateforme de gestion de projets, de réservations et de plannings de laboratoires. Elle propose un espace utilisateur et un espace administrateur communiquant avec une API REST développée avec Symfony.

Angular TypeScript Symfony PHP CSS HTML Doctrine API REST SQLite Docker Docker Desktop GitBucket WinDesign Visual Studio Code Projet en groupe

Date : 20 novembre 2025 au 4 mai 2026

Projet : réalisé en groupe dans le cadre de ma Licence 3 MIAGE.

Fonctionnalités principales : authentification et inscription des utilisateurs, gestion des profils, création et suivi de projets, réservation de laboratoires par date et créneau horaire, suivi du statut des demandes, gestion des documents, notifications, matériels, stages et prestations.

Espace administrateur : gestion des utilisateurs, projets, réservations, laboratoires, matériels, prestations, stages, documents et notifications. L'administrateur dispose également d'un tableau de bord lui permettant de suivre et de traiter les différentes demandes.

J'ai notamment travaillé sur la création des entités et des fixtures, l'authentification, la communication Angular/Symfony et plusieurs fonctionnalités de l'espace administrateur : gestion des contacts, prestations, projets, réservations, laboratoires, le dashboard et le profil administrateur.

Architecture : frontend développé avec Angular et TypeScript utilisant des services HttpClient pour communiquer avec une API REST Symfony. Les données sont gérées avec Doctrine et une base de données relationnelle.

Bilan : ce projet m'a permis de consolider mes compétences en développement full-stack, Angular, Symfony, conception d'API REST, gestion de bases de données avec Doctrine et communication entre frontend et backend. Il m'a également permis de travailler sur une application composée de nombreux modules et de résoudre des problèmes d'intégration entre les différentes parties du projet.

02

Projet universitaire — Licence 3 MIAGE

Medico — Gestion de consultations médicales

Symfony • PHP • Doctrine ORM • Twig • SQLite • Bootstrap • Docker • Git • Bitbucket

Medico est une application web de gestion médicale développée en équipe avec le framework Symfony. Elle permet de gérer des utilisateurs, des consultations, des traitements et des rendez-vous médicaux à partir d'une interface adaptée aux différents profils.

L'application repose sur une architecture MVC et utilise Doctrine ORM pour gérer les données. L'accès aux fonctionnalités varie selon le rôle de l'utilisateur : administrateur, médecin ou patient.

Contexte

Projet réalisé dans le cadre du module Framework Web 2 de la Licence 3 MIAGE.

Période

Du 17 février 2026 au 2 mars 2026

Organisation

Développement collaboratif avec gestion des versions sur Git et Bitbucket.

Mes contributions

  • Développement du formulaire de création d'une consultation.
  • Mise en place de la modification des consultations.
  • Mise en place de la suppression des consultations.
  • Participation à la gestion des autorisations selon les rôles administrateur, médecin et patient.
  • Amélioration de l'interface avec Twig et Bootstrap.
  • Participation à la création du modèle de mise en page commun et du système de thèmes graphiques.
  • Utilisation de Git et Bitbucket pour le suivi du projet et la collaboration.

Fonctionnalités principales

  • Authentification et déconnexion des utilisateurs.
  • Gestion des rôles et des droits d'accès.
  • Création et administration des utilisateurs.
  • Gestion complète des consultations médicales.
  • Association d'un patient et d'un médecin à une consultation.
  • Gestion des traitements associés aux consultations.
  • Gestion des rendez-vous médicaux.
  • Recherche d'utilisateurs et de patients.
  • Tri et pagination des listes.
  • Choix entre plusieurs thèmes graphiques.

Architecture et aspects techniques

Les entités Symfony représentent les différentes données métier de l'application, notamment les utilisateurs, les consultations, les traitements et les rendez-vous. Les relations entre les entités sont gérées avec Doctrine ORM.

Les contrôleurs prennent en charge les requêtes, les vérifications de rôles, la recherche, le tri, la pagination et les opérations CRUD. Les formulaires sont construits avec le composant Form de Symfony et les interfaces sont réalisées avec Twig et Bootstrap.

Bilan

Ce projet m'a permis d'approfondir l'utilisation de Symfony, de Doctrine ORM et de Twig. J'ai également renforcé mes compétences dans la création de formulaires, la gestion des relations entre entités, le contrôle des accès et le développement collaboratif avec Git.

Medico — Gestion de consultations médicales

Application web réalisée au début de ma Licence 3 MIAGE avec le framework Django. Développée en équipe de quatre étudiants, elle permet à un médecin de gérer les consultations de ses patients ainsi que les traitements et les analyses médicales associés.

Python Django SQLite Bootstrap HTML Docker Git Bitbucket Visual Studio Code Projet en groupe

Date : du 3 novembre 2025 au 7 novembre 2025

Contexte : projet universitaire réalisé en équipe de quatre étudiants dans le cadre du module Framework Web 1 de la Licence 3 MIAGE.

Fonctionnalités principales : affichage de la liste et du détail des consultations, ajout, modification et suppression d'une consultation, gestion des traitements associés à chaque consultation et gestion d'analyses médicales.

Architecture : utilisation de l'ORM Django pour gérer les modèles et les relations, de ModelForm pour les formulaires, des vues et templates Django pour l'affichage, de SQLite pour la persistance des données et de Bootstrap pour la mise en forme de l'interface.

Bilan : ce projet m'a permis de découvrir les fondamentaux du framework Django, les migrations, les relations entre modèles, les formulaires, le routage et l'héritage de templates. Il m'a également permis de travailler rapidement en équipe avec Git et Bitbucket.
